## Servicio HTTP

Ejecuta el servicio con `npm start`. El endpoint `GET /health` devuelve `200` y
`{"status":"ok"}` cuando está operativo. Puedes cambiar el puerto con la
variable de entorno `PORT` (por defecto, `3000`).

Ejecuta las pruebas unitarias con `npm test`.
